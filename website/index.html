Local-First Defense

Security & Privacy Architecture

Designed from inception with zero external cloud dependencies. Your behavioral data belongs exclusively to you.

Zero Cloud & Zero Telemetry

No account logins, no telemetry SDKs, no cloud analytics. All raw timestamps and interval calculations reside in a local SQLite file on your PC. Android cloud auto-backup is explicitly disabled.

Host-Locked Localhost APIs

Destructive actions (renaming devices, deleting histories, Wi-Fi TV scanning, engine shutdown) are cryptographically restricted to localhost (127.0.0.1) with strict CORS, preventing LAN CSRF vectors.

Local Wi-Fi Network Transport

Sync occurs directly between your devices over LAN HTTP without third-party brokers. Run OmniScreen on your trusted home network or personal smartphone hotspot.
